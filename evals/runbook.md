# 行为验收

本文件验证本 Skill 的新建、升级和按需调用行为。判据只在 [evals.json](evals.json) 中；`files` 路径相对本目录。

## 执行

1. 选择受本次修改影响的用例。改变共同准则时覆盖新建与升级；改工具时另跑 `python3 -m unittest discover -s tests -v`。
2. 在临时目录复制对应 `files`，保留 Skill 目录名。样本与评估产物只在临时目录改动。
3. 用独立、干净上下文的 agent 或新会话，提供本 Skill、样本位置、输出目录与用例原始 `prompt`。不给它预期答案和判据，不加载本次修改讨论。仅授权本地临时目录中的操作；不执行发布。
4. 让它完成请求，检查实际文件和运行结果，对照 `must_do` / `must_not_do` 判为通过、不通过或有争议。若它需要用户回答，记录阻塞点，不代替用户编造确认。
5. 结果写到本次任务的测试记录，说明执行环境、实际产物、未覆盖项和限制；不把单次运行日志写回 Skill。

没有独立执行环境时可以人工演练，但需标明未运行独立模型验收。静态扫描或口头复述不算行为测试。本组用例是执行测试；发现与自动触发效果需另外在目标运行时验证。
